## `> projects`

### 🎮 AFK — Away From The Keyboard

Projeto desenvolvido na UTFPR utilizando **visão computacional** para permitir o controle de um jogo através de gestos realizados com as mãos diante da webcam.

O projeto utiliza reconhecimento das mãos para transformar movimentos e gestos em comandos dentro do jogo.

**Tech Stack**

`Python` `OpenCV` `MediaPipe` `Pygame` `Pymunk` `Docker` `Git`

**Áreas**

`Computer Vision` `Hand Tracking` `Gesture Recognition` `Game Development`

[→ Ver projeto no GitHub](https://github.com/MarcosV04/AFK)
